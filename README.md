## 📋 프로젝트 개요

**David's Coffee**는 중국 상하이에서 운영되는 커피 원두 및 드립백 주문 플랫폼입니다.  
위챗(WeChat) 환경에 최적화되어 있으며, 모바일 친화적인 인터페이스를 제공합니다.

### 🎯 주요 특징

- ✅ **13종 원두 + 13종 드립백** 카탈로그
- ✅ **NEW/BEST/SEASON OUT** 배지 시스템
- ✅ **실시간 장바구니** 기능 (LocalStorage 저장)
- ✅ **배송비 자동 계산** (상하이 6 RMB / 기타 10 RMB / 200 이상 무료)
- ✅ **주문 내역 클립보드 복사** 기능
- ✅ **위챗 송금 결제** 안내
- ✅ **브라운/아이보리** 테마 디자인
- ✅ **모바일 반응형** 디자인

## 🚀 배포 방법 (Cloudflare Pages)

### Step 1: 파일 준비
```bash
# 프로젝트 폴더 구조 확인
davidscoffee/
├── index.html
├── css/style.css
├── js/data.js
├── js/cart.js
└── js/main.js
```

### Step 2: Cloudflare Pages 배포
1. **Cloudflare 대시보드** 접속: https://dash.cloudflare.com
2. **Workers & Pages** 클릭
3. **Create application** → **Pages** → **Upload assets**
4. Project name: `davidscoffee`
5. **폴더 전체를 드래그 앤 드롭**
6. **Deploy** 클릭

### Step 3: 배포 완료
- URL 생성: `https://davidscoffee.pages.dev`
- 약 30초~1분 소요
